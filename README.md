# LLM_from_Scratch_Sebastian
This repository has python codes based on each chapter in the book Build Large Language Model by Sebastian Raschka

## Appendix A
This section is required to equip you with necessary skills and undersranding of Tensors and their usage in Pytorch.
it also covers few fundamentals of Pytorch required for deep learing model training such automatic differentiation engine.

## Chapter 2
This chapter covers basics of working with Text data such tokenization, converting tokens into vectors, byte pair encoding

## Chapter 3
This chapter covers coding attenstion mechanism from basic self-attention framework to an enhanced one.
it also includes Masking, causal attention and stacking of multiple attention heads into a multi-head attention module.

## Chapter 4
This chapter covers implementing GPT like model from scratch  with all necessary steps like normalizing layers, shortcut connections

## Chapter 5
This chapter covers loading pretrained weights from OpenAI GPT models and creating training and validation set losses as well

## Chapter 6
This chapter covers fine tuning the LLM model for a classification task

## Chapter 7
instruction fine-tuning process of LLM
